# RunMeter v0.1.0 — Windows x64 未署名プレビュー

Codex・Claudeの利用率、リセット日時、トークン履歴を確認するWindows版です。Node.jsやnpmの追加インストールは不要です。

## ダウンロードと利用

[GitHub Releases](https://github.com/bassmicrobe/RunMeter/releases/tag/v0.1.0)から`RunMeterSetup.exe`を取得して実行します。画面表示にはインターネット接続が必要です。CodexまたはClaudeの「接続」から、初回に表示される6桁コードでペアリングします。公式Codex環境・Claude Codeは別途必要です。

AIサービスの認証情報と利用履歴はPC内に保存します。これらをRunMeterの運営サーバーへ送信・保存しません。

## この配布版について

- Windows x64向けのプレビューです。SetupとRunMeter本体はAuthenticode未署名のため、Windowsが発行元を確認できない旨の警告を表示する場合があります。
- Electron 43.8.3、Claude連携用のNode.js 24.22.1を同梱します。
- 隔離した一時データでDesktop・Bridgeの動作、オフライン復帰画面、外部遷移制限、終了処理を自動確認します。ライセンス文書は実際のインストーラーパッケージ内の原文一致を検査します。
- 実Setupによる新規インストール・上書き更新・アンインストールと、SmartScreenの評価は未検証です。これらの検証済みの正式版として公開するものではありません。
- 自動更新はありません。Web画面は公開中の版を読み込みますが、同梱ランタイムの更新には新しいSetupが必要です。

## 配布ファイル

- `RunMeterSetup.exe`：利用者向けインストーラー。ライセンス文書も内包します。
- `RunMeterDesktop-0.1.0-full.nupkg`、`RELEASES`：同じビルドのSquirrelパッケージと一覧。
- `RunMeter-licenses.zip`：実際の配布物から取り出した本体・ブランド・第三者ソフトウェアのライセンス文書。
- `build-info.json`：ソースのコミット、ランタイムの版、署名状態と配布ファイルのハッシュ。
- `SHA256SUMS.txt`：ダウンロード後のファイル一致確認用SHA-256一覧。発行元の署名の代わりにはなりません。

PowerShellで`Get-FileHash .\RunMeterSetup.exe -Algorithm SHA256`を実行し、`SHA256SUMS.txt`の値と比較できます。
